# Jogo Batalha de Turnos 

### Objetivo do projeto e tema: 

O projeto proposto em sala tem como objetivos sintetizar os conteudos da disciplina de Programação Avançada, aplicando-os de modo "divertido" por meio da linguagem C. 

O tema escolhido pela equipe foi o de Jogo de Batalha por Turnos (J3),o qual será executado via terminal.

### Ideia central:

Personagens alternam ações até restar um vencedor. 

### Requisitos do Sistema:

* Criar/selecionar personagens;
* Ações de combate por turno: atacar, defender e usar item;
* Mostrar estado;
* Registrar resultado;
* Inventario simples;

### Limite do escopo:

Sem IA sofisticada ou sistema extenso de habilidades.
